# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the private
security advisory form in the Suluu GitHub repository and include reproduction
steps, affected versions, and the impact you observed.

Maintainers will acknowledge a complete report within five business days and
will coordinate disclosure after a fix is available. Please allow a reasonable
amount of time for investigation before sharing details publicly.

Only the latest released minor version receives security fixes during the 0.x
series.
